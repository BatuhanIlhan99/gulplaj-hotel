## Decisions applied

- A restrained navy-and-white coastal editorial design; stronger hierarchy and generous photographs. This is our design interpretation, not a pixel-copy or measured style claim about the reference hotels.
- Shorten desktop navigation around the principal guest tasks; preserve all existing sections via mobile/footer navigation. Keep accurate section scrolling.
- Hero has a clear stay-planning action and local-discovery link. Never imply live availability or card checkout.
- Introduction emphasises the verified family-run property and uses an authentic courtyard photograph.
- Add four destination cards: Erdek Sahili, Kapıdağ Yarımadası, Kirazlı Manastırı, Ocaklar Sahili, each with a map search link. No invented travel times, opening hours or fees. Kirazlı access note included.
- Add two precisely identified official destination originals; retain watermarks and visible source credits. Source metadata in DESTINATION-SOURCES.json.
- Add practical native FAQ controls, hotel phone in contact/footer and a mobile call/date action bar. Original gallery, calendar, stay summary and payment limitations remain.
